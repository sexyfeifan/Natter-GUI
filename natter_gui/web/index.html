怎样确认映射生效

  1. 在服务卡片中检查原版 LAN / WAN 检测结果。
  2. 用手机关闭 Wi-Fi，通过当前公网地址连接目标服务。
  3. 把实际连接结果记录为人工验证；这不会覆盖原版检测结果。

公网检查服务超时会返回 UNKNOWN。页面可访问只证明连通，播放或下载速度需要另外对比。

更新流程

GitHub 工作流检查上游 Release，更新固定源码，完成验证后构建新镜像。设备安装当前发布版本；面板内的版本检查只查询信息。
